# MoHaZi

증바람(롤 무작위 총력전: 아수라장) 증강 추천 오버레이.

증강 선택 화면의 카드마다 **등급과 한 줄 이유**를 띄워, 게임 시작 때 고른 빌드에 맞는 증강을 몇 초 안에 고르게 돕습니다.

> 개인용(본인·친구)으로 먼저 만들고 있습니다. 공개 배포는 라이엇 정책을 확인한 뒤 결정합니다.

## 어떻게 동작하나

1. **게임 시작 감지**: 라이엇 Live Client Data API(`127.0.0.1:2999`)로 게임 시작과 내 챔피언을 알아냅니다.
2. **빌드 선택**: 화면 구석에 챔피언별 빌드 목록이 뜹니다(예: AP 무한궁 갱플 / 브루저 갱플). 고르지 않으면 무난한 빌드가 기본값입니다.
3. **증강 인식**: 증강 선택 화면이 뜨면 카드 3장의 아이콘을 인식합니다.
4. **등급 표시**: 카드 상단에 `S — 궁 쿨감 · 무한궁 핵심` 같은 배지를 띄웁니다.
5. **리롤 권장 / 빌드 전환 제안**: 세 장 모두 B 이하면 리롤을 권하고, 고른 증강이 다른 빌드에 더 맞으면 작은 배너로 알려줍니다. 결정은 사용자가 합니다.

### 추천 점수

```
score = w_b·빌드 적합도 + w_s·승률(베이지안 보정) + w_p·기존 증강 시너지
```

| 빌드 성격 | 빌드 적합도 | 통계 | 시너지 |
| --- | --- | --- | --- |
| 승률 최우선 | 0.5 | 0.4 | 0.1 |
| 재미/밈 | 0.8 | 0.1 | 0.1 |

## 실행

Node.js 22 이상, Windows, 게임은 **테두리 없는 창 모드 1920×1080**을 기준으로 합니다.

```bash
cd overlay
npm install
npm run dev        # 개발 실행
npm run build      # 빌드
npm run typecheck  # 타입 검사
```

| 단축키 | 동작 |
| --- | --- |
| `Alt+O` | 오버레이 숨기기/보이기 |

## 구조

```
overlay/            Electron + TypeScript + React 오버레이 앱
└─ src/
   ├─ main/         창 생성, 단축키, 게임 감지
   ├─ capture/      화면 캡처 + 증강 인식
   ├─ engine/       추천 엔진 (순수 함수)
   ├─ preload/      IPC 통로
   └─ renderer/     오버레이 UI
data/builds/        챔피언별 빌드 JSON
pipeline/           통계 배치 스크립트 (M4)
tools/              아이콘 다운로드, 태그 추출
```

## 빌드 파일 작성법

`data/builds/<챔피언>.json`에 직접 작성합니다.

```json
{
  "champion": "Gangplank",
  "builds": [
    {
      "id": "gp-ap-ult",
      "name": "AP 무한궁 갱플",
      "style": "fun",
      "default": false,
      "wantTags": { "ult_haste": 1.0, "ap": 0.8, "ability_haste": 0.6 },
      "mustHave": [],
      "avoidTags": ["crit"]
    }
  ]
}
```

- `style`: `fun`(재미/밈) 또는 승률 최우선 빌드. 점수 가중치가 달라집니다.
- `wantTags`: 빌드가 원하는 증강 태그와 가중치
- `mustHave`: 보너스를 줄 필수 증강 ID
- `avoidTags`: 피할 태그

## 주의

- 화면 캡처만 사용하며, 게임 메모리를 읽거나 게임에 입력을 보내지 않습니다.
