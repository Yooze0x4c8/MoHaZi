Three augments. The right pick in seconds.

On the ARAM: Mayhem augment screen, MoHaZi puts a grade and a one-line reason on every card, scored for the build you picked at game start.

Download for Windows Download for Mac

Free · Windows 10 or later, macOS

Try another build. The cards are re-graded instantly.

Sits on top of the game, shows up only when you pick

Grades for your build

When the game starts, a list of builds for your champion appears. Pick one and every card gets an S, A, B or C grade and a reason for that build.

Reroll and build-switch hints

If all three cards are B or lower, it suggests a reroll. If your augments fit another build better, a small banner says so. You make the call.

Picks recorded automatically

The augment you click is remembered and counted toward synergy on the next pick. If it records the wrong one, fix it from the panel.

Install

Windows

  1. Download and run MoHaZi-Setup.exe.
  2. If "Windows protected your PC" appears, click More info → Run anyway. The app is not code-signed.
  3. Set League to borderless or windowed mode and start ARAM: Mayhem.
  4. To quit, right-click the tray icon → Quit. New versions download automatically.

macOS

  1. Download arm64.dmg for Apple silicon or x64.dmg for an Intel Mac.
  2. Drag MoHaZi into Applications.
  3. If an "unidentified developer" warning appears, go to System Settings → Privacy & Security → Open Anyway.
  4. Allow Screen Recording and restart the app. Without it the app cannot read the cards.

The overlay cannot appear over fullscreen mode. Seeing nothing outside a game is normal. Look for the three-card icon in the tray (menu bar on Mac) to check it is running.
