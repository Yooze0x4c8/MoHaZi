증강 세 장, 뭘 골라야 할지 몇 초 만에.

증바람(무작위 총력전: 아수라장) 증강 선택 화면에서 카드마다 등급과 한 줄 이유를 띄워 줍니다. 게임 시작 때 고른 빌드에 맞춰 매깁니다.

윈도우용 받기 맥용 받기

무료 · 윈도우 10 이상, macOS

빌드를 눌러 보세요. 등급이 바로 다시 매겨집니다.

게임 위에 얹혀서, 고를 때만 보입니다

빌드에 맞춘 등급

게임이 시작되면 내 챔피언의 빌드 목록이 뜹니다. 하나 고르면 그 빌드 기준으로 카드마다 S·A·B·C와 이유를 붙입니다.

리롤과 빌드 전환 제안

세 장 모두 B 이하면 리롤을 권하고, 고른 증강이 다른 빌드에 더 맞으면 작게 알려 줍니다. 결정은 내가 합니다.

고른 증강 자동 기록

클릭한 증강을 기억해 다음 선택의 시너지에 반영합니다. 잘못 기록되면 패널에서 바로 고칩니다.

설치

윈도우

  1. MoHaZi-Setup.exe를 받아 실행합니다.
  2. "Windows의 PC 보호" 경고가 뜨면 추가 정보 → 실행을 누릅니다. 코드 서명이 없어서 뜨는 경고입니다.
  3. 롤을 테두리 없는 창 모드나 창 모드로 두고 증바람을 시작합니다.
  4. 끌 때는 트레이 아이콘 우클릭 → 종료. 새 버전은 알아서 받아집니다.

macOS

  1. Apple 칩이면 arm64.dmg, 인텔 맥이면 x64.dmg를 받습니다.
  2. MoHaZi를 응용 프로그램 폴더로 끌어다 놓습니다.
  3. "확인되지 않은 개발자" 경고가 뜨면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기.
  4. 화면 기록 권한을 허용하고 앱을 다시 켭니다. 이 권한이 없으면 카드를 읽지 못합니다.

전체 화면 모드에서는 오버레이가 뜨지 않습니다. 게임 밖에서 화면에 아무것도 안 보이는 건 정상이에요. 트레이(맥은 메뉴 막대)의 카드 세 장 아이콘으로 켜져 있는지 확인하세요.
