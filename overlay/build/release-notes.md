## 바뀐 점 · What's new

**고른 증강을 더 정확하게 기록해요**
- 증강 카드를 누른 클릭으로 고른 증강을 기록합니다. 예전처럼 마우스 위치로 짐작하지 않아서, 고른 뒤 바로 마우스를 움직여도 맞게 기록돼요.

**창 모드·다른 모니터에서도 떠요**
- 롤 창의 위치와 크기를 따라가서, 창 모드나 보조 모니터에서도 카드 위에 등급이 뜹니다. (전체 화면 모드는 여전히 안 돼요. 테두리 없는 창 모드를 써 주세요.)

**설치할 때 언어를 고를 수 있어요**
- 설치 파일을 켜면 한국어 / English를 고를 수 있고, 고른 언어로 앱이 나옵니다. 카드 이름은 롤 클라이언트 언어로 읽으니 둘이 달라도 괜찮아요.
- 언어를 바꾸려면 설치 파일을 다시 실행해 주세요. 자동 업데이트는 고른 언어를 그대로 둡니다.

**조금 더 가벼워졌어요**
- 증강 화면이 아닐 때 인식 작업을 일찍 끝내 CPU를 덜 씁니다.

---

**More accurate augment tracking**
- The app now records your pick from the card you actually click, instead of guessing from the mouse position. Moving the mouse right after picking no longer causes wrong records.

**Windowed mode and other monitors**
- The overlay follows the League window, so grades show up in windowed mode and on secondary monitors. (Fullscreen mode is still not supported. Please use borderless.)

**Choose the language when installing**
- The installer asks for 한국어 / English, and the app uses that language. Card names are still read in your League client language, so the two can differ.
- To change it, run the installer again. Auto-updates keep your choice.

**Lighter**
- Recognition stops early when no augment screen is shown, using less CPU.
